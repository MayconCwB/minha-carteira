⚙️ Chaves do Projeto Firebase

Nota: a sincronização só funciona com as chaves preenchidas.

Como obter essas chaves no Firebase grátis (passo a passo)
  1. Acesse o console.firebase.google.com com sua conta Google.
  2. Clique em Criar um projeto (plano gratuito Spark padrão).
  3. Vá em Authentication > Começar > Ativar os provedores E-mail/senha e Google.
  4. Vá em Firestore Database > Criar banco de dados (modo de teste ou regras permitindo leitura/gravação autenticada para o próprio uid).
  5. Nas Configurações do Projeto (ícone da engrenagem ⚙️) > Seus aplicativos > Adicionar Web (ícone </>) > Copiar o objeto firebaseConfig e colar nos campos acima.

📲 Instalar como App (PWA)

Para usar em tela cheia como se fosse um app nativo:

  • No Chrome / Edge (Desktop): Clique no ícone de computador/instalação na barra de endereços ou no menu (...) > "Instalar Minha Carteira".
  • No Android (Chrome): Toque nos três pontinhos no canto superior > "Adicionar à tela inicial" ou "Instalar aplicativo".
  • No iPhone / iPad (Safari): Toque no botão de Compartilhar (quadrado com seta para cima) > "Adicionar à Tela de Início".
