⚙️ Configurar a nuvem (só uma vez)

Ativa o login e a sincronização entre aparelhos via Firebase (gratuito).

1) Crie um projeto grátis em console.firebase.google.com
2) Authentication → Sign-in method → ative E-mail/senha e Google
3) Ative o Firestore Database (modo de produção)
4) Configurações do projeto → Seus apps → app Web → copie o objeto firebaseConfig e cole abaixo:

🔒 Regras recomendadas para o Firestore

No console do Firestore, aba Rules, cole:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /carteiras/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
